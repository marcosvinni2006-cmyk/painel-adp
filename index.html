Como ler estes números
  • Cancelamento = cliente com resultado de renovação “Churned”. Receita perdida = soma do ARR desses clientes.
  • A base é uma foto, sem datas: os números mostram associação, não causa.
  • Com filtros, os quartis são recalculados só para os clientes filtrados. Grupos pequenos oscilam muito.
  • 11 clientes têm precisão de folha acima de 100%, valor impossível: vale checar a origem do dado.
